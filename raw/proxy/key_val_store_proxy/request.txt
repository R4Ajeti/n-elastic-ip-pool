Target URL:
- https://api.keyval.org/get/{KEY}
- https://api.keyval.org/set/{KEY}/{VALUE}
HTTP method: GET
Required headers:
- Accept: application/json, text/plain
- User-Agent: n-elastic-ip-pool/0.1
- Authorization: Bearer <KEY_VAL_AUTH_TOKEN> (private compatible providers only)
Authentication: Optional. The public KeyVal provider needs no token. Never include a real token, secret, or proxy credential in examples.

This request documents the KeyValStoreProxy calls used by the service layer. The service hashes the configured KeyVal key and stores a compact JSON list of safe working proxy values. The proxy layer handles the KeyVal endpoint URL, GET request construction, timeout, response parsing, and provider errors.
